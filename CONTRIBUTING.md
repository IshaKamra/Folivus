# Contributing to Folivus AI

Thank you for helping safeguard global crop yields! To maintain a production-grade codebase, please follow these development guidelines:

## Code Quality Standards
1. **Formatting:** Enforce clean, readable code formatting across all `.py` files.
2. **Modularity:** Do not write hardcoded paths. All variables must be exposed inside `config/config.yaml`.
3. **Type Hinting:** Use explicit Python type hints where possible for function arguments.

## Pull Request Process
1. Fork the repository and create your feature branch: `git checkout -b feature/amazing-enhancement`.
2. Ensure no cache artifacts (`__pycache__` or `.ipynb_checkpoints`) are staged.
3. Open a Pull Request pointing to our `main` branch with a clear description of your engineering modifications.
